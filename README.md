# SEC Filings RAG Assistant

## Business problem

Analysts spend hours locating and cross-checking answers in 10-K filings.
This tool returns answers with citations to filing, section and passage,
and refuses when the filings do not support an answer.

## \## Scope

## 

## Companies: MSFT, ORCL, CRM, ADBE, NOW, INTU, WDAY, PANW

## 

## Filings: 10-K, last 3 fiscal years

## 

## \## Tools

## 

## Python, requests, BeautifulSoup, sentence-transformers (all-MiniLM-L6-v2), ChromaDB
